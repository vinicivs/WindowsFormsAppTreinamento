# WindowsFormsAppTreinamento

Aplicação Windows Forms de exemplo para treinamento.

## Descrição

Projeto de exemplo em .NET Framework 4.7.2 que contém uma aplicação Windows Forms. Ideal para aprender sobre formulários, eventos e desenvolvimento desktop com Visual Studio.

## Requisitos

- Windows 10/11
- Visual Studio 2019/2022/2026 com suporte a .NET Framework
- .NET Framework 4.7.2 instalado

## Como abrir

1. Clone o repositório:

   git clone https://github.com/vinicivs/WindowsFormsAppTreinamento.git

2. Abra a solução no Visual Studio: `WindowsFormsAppTreinamento.sln` (ou o arquivo .csproj dentro da pasta do projeto).

## Compilar e executar

- No Visual Studio, selecione a configuração (Debug/Release) e clique em "Iniciar" (F5) para executar a aplicação.
